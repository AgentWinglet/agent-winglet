A folder of research papers that have inspired Winglet.

Helps coding agents quickly look up the papers to keep the implementation grounded.

## Papers

- **AgentDiet: Reducing Cost of LLM Agents with Trajectory Reduction** — an inference-time approach that strips useless, redundant, and expired information from an agent's trajectory, cutting input tokens by 40-60% and total cost by 21-36% with no loss in task performance.
- **The Complexity Trap: Simple Observation Masking Is as Efficient as LLM Summarization for Agent Context Management** — finds that simply masking older tool-call observations halves context-management cost versus LLM-based summarization while matching (and sometimes beating) its solve rate; a hybrid of the two cuts cost further still.
